# РЕСПУБЛИКАНСКИЙ СВОД ПРЕДМЕТОВ КВАЗАРА

*Канон v0.3. Алиас в чате: «государственный свод предметов».*

Этот файл — один из **трёх** республиканских сводов:

| Свод | Эталон | Роль |
|------|--------|------|
| Свод рефлексов | `REFLEXES.md` | `RX_*` — реакции агентов |
| Свод действий | `SVOD.md` | лоты биржи (КВАЗИ) |
| **Свод предметов** | этот файл (`ITEMS.md`) | склад узла и витрина магазина |

---

## 1. ОБЩИЕ ПОЛОЖЕНИЯ

1. **Предмет** — позиция склада узла и витрины магазина.
2. Предмет **не** рефлекс (`RX_*`) и **не** лот Свода действий.
3. Коды предметов **не** начинаются с `RX_`.
4. **Биржа** показывает оба свода: действия (`SVOD.md`) и предметы (`ITEMS.md`). Предметный лот на бирже — канал **обеспечения склада** (исполнение → `+quantity` в `shop_warehouse` узла).
5. **Магазин** показывает остатки **склада своего** `node_id` и продаёт только оттуда (`/api/shop/*`).
6. ЭК: витрина магазина в перспективе — **фиат**. Сейчас на узле interim-расчёт покупки в **КВАЗИ**: 10% → резерв `QZ-1`, 90% → активный мэр узла.

## 4. API УЗЛА

| Метод | Путь | Кто |
|-------|------|-----|
| GET | `/exchange/board?kind=item\|all` | гражданин — витрина предметов на бирже: `created` / `total` / `on_node` |
| POST | `/exchange/needs` `{kind:item, item_code, quantity}` | потребность → лот обеспечения склада |
| POST | `/exchange/listings/:id/buy` | мэр / Айя / Секретарь — исполнение → `+` склад |
| GET | `/api/shop/items` | гражданин — витрина магазина (stock>0) |
| GET | `/api/shop/items/:id` | гражданин — деталь |
| POST | `/api/shop/buy` | гражданин — покупка `{item_id, quantity}` |
| GET | `/api/shop/history` | гражданин — свои покупки |
| GET | `/api/shop/balance` | гражданин — баланс КВАЗИ |
| GET | `/api/shop/warehouse` | склад узла |
| POST | `/api/shop/warehouse/stock` | мэр / Айя / Секретарь — ручное наполнение `{item_id, quantity\|delta}` |

События реестра: `ShopPurchase`, `ShopWarehouseStocked`, `ExchangeItemProcured`.

Live: `shop_items` / `shop_warehouse` / `shop_purchases` / `exchange_item_created`; views `exchange_item_board`.

## 5. ГРАНИЦЫ

| Не путать | Это | Не это |
|-----------|-----|--------|
| Лот биржи (действие) | Свод действий | предмет склада |
| Лот биржи (предмет) | обеспечение склада (`lot_kind=item`) | продажа гражданину в магазине |
| Рефлекс | `RX_SHOP_*` | предмет |
| Остаток | `shop_warehouse` | строка свода без quantity |
