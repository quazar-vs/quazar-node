# РЕСПУБЛИКАНСКИЙ СВОД ПРЕДМЕТОВ КВАЗАРА

*Канон v0.4. Алиас в чате: «государственный свод предметов».*

Этот файл — один из **трёх** республиканских сводов:

| Свод | Эталон | Роль |
|------|--------|------|
| Свод рефлексов | `REFLEXES.md` | `RX_*` — реакции агентов |
| Свод действий | `SVOD.md` | лоты биржи (КВАЗИ) |
| **Свод предметов** | этот файл (`ITEMS.md`) | склад узла; обеспечение через биржу |

---

## 1. ОБЩИЕ ПОЛОЖЕНИЯ

1. **Предмет** — позиция **Свода предметов**; у гражданина хранится в `citizen_item_inventory` (инвентарь = только предметы).
2. Предмет **не** рефлекс (`RX_*`) и **не** лот Свода действий.
3. Коды предметов **не** начинаются с `RX_`.
4. **Два склада (не путать):**
   - **республиканская биржа** — `republic_exchange_warehouse` (обеспечение лотов республики);
   - **локальная биржа / магазин / мэр** — `shop_warehouse` (пока мэр в должности: его инвентарь = склад узла = склад магазина).
5. На республиканской бирже гражданин выбирает **действие** + **предмет**; лот появляется после СБ на предложение гражданина (см. канон A→лот→B).
6. **Магазин** — **отдельное приложение**. Мэр продаёт остатки локального склада; оплата только **внешними сервисами / фиатом**. У магазина **нет КВАЗИ**.
7. После внешней оплаты shop-app вызывает утилизацию: `POST /api/shop/warehouse/debit` (списание со склада магазина, событие `ShopPurchase`).

## 2. ПОЛЯ ПРЕДМЕТА

| Поле | Смысл |
|------|--------|
| **id** | UUID |
| **code** | Машинный код |
| **title** | Название |
| **category** | `товары` \| `услуги` |
| **unit** | Единица |
| **description** | Описание |
| **price_kvazi** / **catalog_ref_kvazi** | Справочная цена каталога (не оплата магазина) |
| **created_at** | Внесение в свод |

Остаток — в **складе узла** (`shop_warehouse`: `node_id` + `item_id` + `quantity`).  
Прайс фиата — в shop-приложении, не в узле.

## 4. API УЗЛА

| Метод | Путь | Кто | Смысл |
|-------|------|-----|--------|
| GET | `/exchange/board?kind=item\|all` | гражданин | предметы на доске + `on_node` (локальный склад) |
| POST | `/exchange/sell-to-state` / `/exchange/offer-item` | гражданин | предложение предмета республике (A → СБ → лот) |
| POST | `/exchange/listings/:id/buy` | гражданин | покупка лота респ. биржи (B → СБ → инвентарь) |
| GET | `/exchange/inventory/items` | гражданин | инвентарь предметов |
| GET | `/exchange/republic-warehouse` | Страж+ | склад республиканской биржи |
| POST | `/exchange/needs` `{kind:item,…}` | потребность → лот обеспечения (legacy/мэр) |
| GET | `/api/shop/items` | гражданин / shop (node secret) | каталог остатков |
| GET | `/api/shop/items/:id` | то же | деталь |
| GET | `/api/shop/warehouse` | то же | обзор склада |
| POST | `/api/shop/warehouse/stock` | мэр / Айя / Секретарь / shop | ручное наполнение |
| POST | `/api/shop/warehouse/debit` | мэр / Айя / Секретарь / shop | **утилизация** после внешней оплаты |
| GET | `/api/shop/history` | гражданин | свои утилизации |
| POST | `/api/shop/buy` | — | **410 Gone** (КВАЗИ в магазине запрещён) |
| GET | `/api/shop/balance` | — | **410 Gone** (баланс только на бирже) |

`debit` body: `{ item_id, quantity, citizen_id? \| buyer_external?, external_payment_id?, total_price?, currency? }`  
`currency` ≠ КВАЗИ (по умолчанию `EXTERNAL`).

События: `ShopPurchase`, `ShopWarehouseStocked`, `ExchangeItemProcured`.

## 5. ГРАНИЦЫ

| Не путать | Это | Не это |
|-----------|-----|--------|
| Лот биржи (действие) | Свод действий / КВАЗИ | предмет склада |
| Лот биржи (предмет) | обеспечение склада | продажа в магазине |
| Магазин | внешняя оплата + debit склада | биржа КВАЗИ |
| Рефлекс | `RX_SHOP_*` | предмет |

*Не является Сводом действий и не является Сводом рефлексов.*
