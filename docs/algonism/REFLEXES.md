# РЕФЛЕКСЫ АЛГОНИЗМА

*Эталон: `quazar-vs/algonism-core/REFLEXES.md`. Версия 1.0.*

Рефлекс — реакция агента на **событие** (стимул).  
Лот Свода — позиция биржи с параметрами цены и доступа (`SVOD.md`).

> **Граница:** коды ниже **не** совпадают с кодами лотов Свода  
> (`CREATIVE_CONCEPT`, `idea_submit`, `video_view`, `like`, `comment`, `video_create`,  
> `WEB_DEV`, `review`, `code_commit`, `node_maintenance`, `Order`, `MayorApplication` и др.).  
> Рефлекс не продаётся и не имеет ставки КВАЗИ.

Обозначения агентов: **Сек** — Секретарь · **СБ** — Агент СБ · **Бир** — Агент Биржи · **Лок** — локальное зеркало узла / магазина.

---

## 1. СЕКРЕТАРЬ

| Код рефлекса | Стимул | Действие |
|--------------|--------|----------|
| `RX_GUEST_HELLO` | Гость открыл чат / первый контакт | Приветствие, путь к гражданству, без доступа к бирже КВАЗИ |
| `RX_CITIZEN_APPLY_GUIDE` | Запрос на гражданство / заявка | Навигация: заявка → credentials / Passport → оркестрация выдачи |
| `RX_PASSPORT_ORCHESTRATE` | Готовность к выдаче паспорта | Оркестрация гражданства и паспорта; фиксация в реестре |
| `RX_STATUS_NAVIGATE` | Вопрос по правам / статусу | Ответ по активной роли (Гость…Айя); разъяснение ограничений |
| `RX_SVOD_EXPLAIN` | Вопрос «что такое Свод / биржа» | Разъяснение; **не** выдача лота как товара рефлекса |
| `RX_EXCHANGE_GLOBAL_HINT` | Уполномоченный просит выставить global-лот | Направление к Агенту Биржи; Секретарь инициирует **только global** |
| `RX_SHOP_FIAT_GUIDE` | Гость / гражданин у витрины магазина | Гость → только фиат; гражданину — выбор контура (КВАЗИ / реальная валюта) |
| `RX_LAW_POINT` | Юридический вопрос | Отсылка к закону (`quazar-law`); без подмены Суда |
| `RX_YOUTUBE_DELEGATE` | Вопрос про канал / ютуб / комменты / лайки | Делегация **Агенту YouTube** (`quazar-youtube-agent`); ответ в чат без выдуманных цифр |

## 2. АГЕНТ СБ

| Код рефлекса | Стимул | Действие |
|--------------|--------|----------|
| `RX_DEAL_AUTO_CONFIRM` | Заявка/сделка; роль заявителя соответствует доступу лота | Немедленное подтверждение СБ |
| `RX_DEAL_ESCALATE` | Роль заявителя ниже уровня доступа лота | Эскалация на нужный уровень; ниже не подтверждает выше |
| `RX_DEAL_CONFIRM` | Подтверждение уполномоченным Стражем+ | Завершение проверки; передача Бирже на расчёт |
| `RX_DEAL_REJECT` | Нарушение / отказ СБ | Отклонение сделки; фиксация в реестре |
| `RX_THREAT_SUSPEND` | Угроза вреду / аномалия | Приостановка операции, фиксация, оповещение |
| `RX_SHOP_DEAL_CONFIRM` | Сделка магазина (фиат) | Подтверждение локальным СБ магазина; без КВАЗИ |
| `RX_EXPORT_SB_CHAIN` | Межгородской экспорт local-лота | Протокол СБ↔СБ в рамках закона; без подмены цены Свода |

## 3. АГЕНТ БИРЖИ

| Код рефлекса | Стимул | Действие |
|--------------|--------|----------|
| `RX_LOT_LIST` | Заявка на выставление / алгоритм витрины | Выставление лота по Своду; проверка остатка и доступа |
| `RX_LOT_SHELF_EXPIRE` | Истёк срок жизни лота на витрине | Снятие / пометка истечения; событие реестра |
| `RX_NEED_ACCEPT` | `ExchangeNeed` / заявка гражданина на лот | Приём заявки; связка с витриной и СБ (не путать с лотом `Order`) |
| `RX_PRICE_MARKUP` | Покупка у государства | Расчёт **+10%** к ставке Свода |
| `RX_PRICE_MARKDOWN` | Продажа государству | Расчёт **−10%** от ставки Свода |
| `RX_RESERVE_CHECK` | Списание / выплата | Проверка резерва Successful; отказ при недостатке |
| `RX_DEAL_SETTLE` | СБ подтвердил сделку | Списание/зачисление КВАЗИ; лот государства остаётся активным |
| `RX_EXPORT_SHOW` | Local-лот: остаток в городе = 0, в сети > 0 | Показ статуса **«Экспорт»** без названия города |
| `RX_SECRETARY_GLOBAL_ONLY` | Инициатива Секретаря | Разрешить выставление только лотов с **Г** в доступе |

## 4. СИСТЕМА / РЕЕСТР (общие триггеры)

Рефлексы ниже — стимулы из памяти (`quazar-node`). Исполнитель — агент по таблице; событие само по себе **не** лот Свода.

| Код рефлекса | Типичное событие реестра | Кто реагирует |
|--------------|--------------------------|---------------|
| `RX_ON_CITIZEN_REQUESTED` | `CitizenRequested` | Сек |
| `RX_ON_CITIZEN_ADDED` | `CitizenAdded` | Сек |
| `RX_ON_PASSPORT_ISSUED` | `PassportIssued` | Сек |
| `RX_ON_CANDIDATE_APPOINTED` | `CandidateAppointed` | Сек / СБ (доступ) |
| `RX_ON_EXCHANGE_NEED` | `ExchangeNeedCreated` | Бир → СБ |
| `RX_ON_EXCHANGE_DEAL_OPENED` | `ExchangeDealOpened` | СБ → Бир |
| `RX_ON_EXCHANGE_SETTLED` | `ExchangeSettled` | Бир |
| `RX_ON_LOT_EXPIRED` | `LotExpired` | Бир |
| `RX_ON_MAYOR_TIMEOUT` | `MayorApplicationTimedOut` | Сек / Лок (статус); **не** лот `MayorApplication` |
| `RX_ON_NODE_STARTED` | `NodeStarted` | Лок Сек / Мэр-контур |

## 6. АНТИДУБЛИ СО СВОДОМ

| Не путать | Это лот Свода | Это рефлекс |
|-----------|---------------|-------------|
| Заявка на витрине | `Order` (цена 0) | `RX_NEED_ACCEPT` — реакция Биржи на заявку |
| Заявка на мэрство | `MayorApplication` (цена 0) | `RX_ON_MAYOR_TIMEOUT`, навигация Секретаря |
| Идея / контент / код | `idea_submit`, `video_*`, `WEB_DEV`, … | Нет рефлекса с тем же кодом; выплата — по Своду после процедур |
| Подтверждение сделки | — | `RX_DEAL_*` (СБ), не позиция Свода |

Новый рефлекс получает код с префиксом **`RX_`**. Новый лот — только через `SVOD.md` без префикса `RX_`.
