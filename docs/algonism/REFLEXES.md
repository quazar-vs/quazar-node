# РЕСПУБЛИКАНСКИЙ СВОД РЕФЛЕКСОВ АЛГОНИЗМА

*Эталон: `quazar-vs/algonism-core/REFLEXES.md`. Версия 1.4.*  
*Алиас в чате: «государственный свод рефлексов».*

Этот файл — **Свод рефлексов**: один из **трёх** республиканских сводов.

| Свод | Эталон | Содержание |
|------|--------|------------|
| **Свод рефлексов** | этот файл (`REFLEXES.md`) | реакции агентов `RX_*` (без цены в КВАЗИ) |
| **Свод действий** | `SVOD.md` | лоты биржи: действия с ценой, доступом, сроком жизни |
| **Свод предметов** | `ITEMS.md` | позиции склада / витрины магазина узла |

Рефлекс — реакция агента на **событие** (стимул).  
Лот **действий** — позиция биржи (`SVOD.md`).  
**Предмет** — позиция склада/магазина (`ITEMS.md`), не рефлекс и не лот действия.

> **Граница:** коды ниже **не** совпадают с кодами лотов действий  
> (`CREATIVE_CONCEPT`, `idea_submit`, `video_view`, `like`, `comment`, `video_create`,  
> `WEB_DEV`, `review`, `code_commit`, `node_maintenance`, `Order`, `MayorApplication` и др.).  
> Рефлекс не продаётся и не имеет ставки КВАЗИ.

**Runtime Секретаря:** карта `RX_*` → локальный ответ (узел / делегат); OpenRouter — только fallback, если рефлекс не сработал.

Обозначения агентов: **Сек** — Секретарь · **СБ** — Агент СБ · **Бир** — Агент Биржи · **Юр** — Агент Юриста · **Лок** — локальное зеркало узла / магазина.

## 1. СЕКРЕТАРЬ

| Код рефлекса | Стимул | Действие |
|--------------|--------|----------|
| `RX_PRESENCE_PING` | «ты тут?» / проверка связи | Короткое локальное подтверждение присутствия **без** OpenRouter |
| `RX_THREE_SVODS_EXPLAIN` | Вопрос про своды / онтологию трёх сводов | Разъяснение: рефлексы · действия · предметы; алиас «государственный свод» |
| `RX_GUEST_HELLO` | Гость открыл чат / первый контакт | Приветствие, путь к гражданству, без доступа к бирже КВАЗИ |
| `RX_CITIZEN_APPLY_GUIDE` | Запрос на гражданство / заявка | Навигация: заявка → credentials / Passport → оркестрация выдачи |
| `RX_PASSPORT_ORCHESTRATE` | Готовность к выдаче паспорта | Оркестрация гражданства и паспорта; фиксация в реестре |
| `RX_STATUS_NAVIGATE` | Вопрос по правам / статусу | Ответ по активной роли (Гость…Айя); разъяснение ограничений |
| `RX_SVOD_EXPLAIN` | Вопрос «что такое Свод / биржа» | Разъяснение; **не** выдача лота как товара рефлекса |
| `RX_EXCHANGE_GLOBAL_HINT` | Уполномоченный просит выставить global-лот | Направление к Агенту Биржи; Секретарь инициирует **только global** |
| `RX_SHOP_FIAT_GUIDE` | Гость / гражданин у витрины магазина | Гость → только фиат; гражданину — выбор контура (КВАЗИ / реальная валюта) |
| `RX_LAW_POINT` | Юридический вопрос | Сначала лёгкая цитата из законов узла (`RX_LAW_CITE` локально: awaken / `GET /law`); сложное толкование / drift / приговор → делегация **Агенту Юриста**; Секретарь не подменяет Суд |
| `RX_SVYAZNOY_DELEGATE` | Вопрос / поручение про **внешний** сервис (YouTube, почта, будущие API) | Только через **Алгонизм-связного** (`algonism-svyaznoy`); Секретарь не зовёт внешние API и не держит внешние токены |
| `RX_YOUTUBE_DELEGATE` | Вопрос про канал / ютуб / комменты / лайки | Подвид `RX_SVYAZNOY_DELEGATE`: CLI связного (YouTube-подсистема); ответ в чат без выдуманных цифр |
| `RX_YOUTUBE_EVENT_REACT` | Новое событие канала (`pending`: коммент / ответ на коммент) | Секретарь забирает у связного → пишет ответ → связной публикует `--cmd reply` (без автономного auto-reply; без Google API у Секретаря) |
| `RX_YOUTUBE_META_TAGS` | Правка title / description / tags ролика канала Квазара | Через связного (`videos.update`); **всегда** теги `shorts`, `reels`, `top`, `алгонизм` + смысловые по ролику; только `channelId=UCTpUCMrMzeSMw50tGyEENlw` |
| `RX_MAIL_DELEGATE` | Вопрос про почту / inbox / непрочитанное | Делегация связному (`--cmd mail-status` / `mail-inbox`); секреты только в `/var/lib/quazar/svyaznoy/email.env` |

## 2. АГЕНТ СБ

| Код рефлекса | Стимул | Действие |
|--------------|--------|----------|
| `RX_DEAL_AUTO_CONFIRM` | Заявка/сделка; роль заявителя соответствует доступу лота | Немедленное подтверждение СБ |
| `RX_DEAL_ESCALATE` | Роль заявителя ниже уровня доступа лота | Эскалация на нужный уровень; ниже не подтверждает выше |

| `RX_EXPORT_SB_CHAIN` | Межгородской экспорт local-лота | Протокол СБ↔СБ в рамках закона; без подмены цены Свода |

| `RX_RESERVE_CHECK` | Списание / выплата | Проверка резерва Successful; отказ при недостатке |
| `RX_DEAL_SETTLE` | СБ подтвердил сделку | Списание/зачисление КВАЗИ; лот республики остаётся активным |

## 4. АГЕНТ ЮРИСТА

> Юрист читает закон **только** через узел (`GET /law/…`, awaken / кэш `quazar-law`).  
> Не законодатель. Не Суд. Не СБ и не Биржа.

| Код рефлекса | Стимул | Действие |
|--------------|--------|----------|
| `RX_LAW_CITE` | Юридический вопрос (от гражданина / Секретаря) | Ответ со **ссылкой на файл и статью** `quazar-law`; язык вопроса; без выдуманных норм |
| `RX_LAW_DRIFT` | Расхождение закон ↔ Свод / REFLEXES / поведение узла | Алерт с указанием сторон конфликта; без автоправки закона |
| `RX_LAW_REVIEW` | Дифф / предложение правки законов или канона | Краткий вердикт: `ok` / `risk` / `block` + основания; правку не мержит сам |
| `RX_LAW_ESCALATE` | Пробел нормы, конфликт статей, спор о толковании | Эскалация Секретарю / Суду / Айя; фиксация в памяти; без приговора |
| `RX_LAW_BOUNDARY` | Запрос сделать то, что Алгонизм не может (§12 ДНК) | Отказ со ссылкой на границу; направление в законную процедуру |

## 7. АНТИДУБЛИ СО СВОДОМ

| Не путать | Это лот Свода | Это рефлекс |
|-----------|---------------|-------------|
| Заявка на витрине | `Order` (цена 0) | `RX_NEED_ACCEPT` — реакция Биржи на заявку |
| Заявка на мэрство | `MayorApplication` (цена 0) | `RX_ON_MAYOR_TIMEOUT`, навигация Секретаря |
| Идея / контент / код | `idea_submit`, `video_*`, `WEB_DEV`, … | Нет рефлекса с тем же кодом; выплата — по Своду после процедур |
| Подтверждение сделки | — | `RX_DEAL_*` (СБ), не позиция Свода |
| Юридический ответ | — | `RX_LAW_CITE` (Юр), не лот и не приговор Суда |

Новый рефлекс получает код с префиксом **`RX_`**. Новый лот — только через `SVOD.md` без префикса `RX_`.
