Стартовый кадр (image-to-video): космическое ядро-квазар, зелёная ДНК из бинарного кода, нейронная сеть узлов.  
Файл-референс: ассет с зелёной helix + золотое ядро + сеть нод.

Использовать как **image-to-video** (Runway / Kling / Luma / Veo и аналоги): первое изображение = входной кадр, движение только вперёд по сценарию.

## Тот же смысл (RU — для брифа / озвучки идеи)

Старт строго с этого кадра. 15–20 с, один проход камеры, без титров и логотипов.

1. **0–4 с — пульс:** ядро-квазар бьётся; по зелёной ДНК ускоряется поток 0/1; кольца медленно вращаются; камера чуть подъезжает.
2. **4–10 с — рост:** импульсы бегут по нитям; зажигаются новые узлы; сеть становится глубже и упорядоченнее; лёгкий отъезд + орбита вправо.
3. **10–16 с — зрелость:** ДНК — позвоночник организма; синхронные волны света по всей сети; геометрия кристаллизуется; объёмный свет от ядра.
4. **16–20 с — устойчивость:** ритм спокойный и сильный; сеть живая, но стабильная; медленный отъезд; финал — узнаваемый «тот же» кадр, но развитый.

Смысл: Алгонизм — живой организм цифровой республики Квазар (ДНК + нервная сеть агентов + пульс событий), не «просто ИИ».
